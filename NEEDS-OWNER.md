# Decisões que dependem das responsáveis pelo projeto

## 1. Identidade e objetivo

O repositório se chama `AgenciaViagens`, mas a página se apresenta como **TechJourney**, um guia de carreiras em TI para a Feira de Profissões 2026. Confirmem qual é o nome e o objetivo finais. Se o nome do repositório estiver desatualizado, atualizem também a apresentação, a descrição do GitHub e o material da feira.

## 2. Valores de remuneração

Os valores exibidos nos cartões (`index.html`) e no simulador (`script.js`) não têm fonte, localidade, período nem metodologia informados. O PR passa a identificá-los como **exemplos ilustrativos** para evitar que pareçam uma pesquisa. Para transformá-los em dados reais, escolham fontes verificáveis e registrem data, região, nível de experiência e critérios. Se a proposta for apenas demonstrar a interação, mantenham a indicação de que são fictícios.

## 3. Textos e imagens

Revisem as descrições de carreira, mercado e cursos em `script.js` para conferir se representam o conteúdo que desejam ensinar. Confirmem também a origem e a permissão de uso das imagens em `assets/`, registrando os créditos quando necessário. O PR não substitui esses materiais.

## 4. Publicação e validação

Escolham onde o site será publicado, testem em celular e computador e façam uma revisão com participantes antes da apresentação. O projeto é estático e não precisa de banco de dados ou API para as funções atuais.
